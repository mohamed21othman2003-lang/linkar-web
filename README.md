# لينكار · Linkar — الموقع (فرونت إند)

منصة سعودية تربط العميل بمقدّمي خدمات العناية بالسيارات: يقارن ويحجز ويدفع ويتابع.
النسخة دي **فرونت إند بس** ببيانات تجريبية — مفيش باك إند ولا دفع حقيقي لسه.

- **التصميم المرجعي:** صفحة `linkar-site-final` في ملف الفيجما (فريمات `V2-xx` و`W2-xx`).
  صفحة `archive · website v1` نسخة قديمة ومش مرجع.
- **اللغات:** عربي (افتراضي) وإنجليزي من زرار `En` في الهيدر.

## تشغيل محلي

```bash
npm install
npm run dev        # http://localhost:3000
npm run build && npm start   # نسخة الإنتاج
```

## دخول تجريبي

| الحالة | البيانات |
|---|---|
| عميل حالي (برقم الجوال) | `0551234567` ورمز التحقق `1234` |
| عميل حالي (بالإيميل) | `mohammed.salem@example.com` وأي باسورد |
| عميل جديد (أول دخول) | أي رقم جوال سعودي تاني ورمز التحقق `1234` — كود الدعوة `SARA4K` |

الزائر بيشوف الرئيسية V2-02، والمسجّل بيشوف V2-01.

## النشر (Vercel)

مفيش متغيرات بيئة مطلوبة للنسخة دي. أي أسرار مستقبلاً (مفاتيح الدفع، قاعدة البيانات…) مكانها
متغيرات البيئة في Vercel أو `.env` محلياً — `.env` متجاهَل في git ومايتعملوش commit.
